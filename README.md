
# Zentry

A comprehensive expense tracking mobile application built with React Native and Expo, featuring robust data management with SQLite and Drizzle ORM.

💸 Track income and expenses with detailed categorization

📊 Visualize spending patterns with interactive charts

📅 Monthly budgeting

🌐 Multi-language support (i18n)

🔒 Secure local data storage with SQLite

🎨 Clean UI with NativeWind and Gluestack UI

📱 Cross-platform (iOS & Android)


## 🛠 Tech Stack
- Frontend:
  
  - Expo

  - React Native

  - NativeWind

  - Gluestack UI

  - React Native Gifted Charts

  - Lucide React Native


- State & Data:

  - Expo SQLite

  - Drizzle ORM

  - React Native Async Storage


- Utilities:

  - Day.js

  - i18next
